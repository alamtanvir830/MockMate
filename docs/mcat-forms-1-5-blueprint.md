## Quality Gates (per question)

Every question in every form must satisfy ALL of the following before being counted:

1. **Unique ID** — no ID appears in any other form or QB file
2. **Correct answer is unambiguous** — exactly one choice is correct; verified by second-pass reasoning
3. **Three named distractors** — each wrong answer represents a specific, named reasoning error
4. **wrongAnswerExplanations** — at least 3 of 4 choices have explicit explanations
5. **No answer leakage** — no choice text appears verbatim (≥8 chars) in the passage within 10 words
6. **teachingPoint** — one clear, concise takeaway (not a restatement of the question)
7. **relatedTopics** — minimum 3 keywords
8. **Discipline/content category accuracy** — discipline matches AAMC content outline exactly
9. **Foundational Concept** — FC string starts with "FC [1-10]:"
10. **Scientific Skill** — 'Skill 1', 'Skill 2', 'Skill 3', or 'Skill 4' only
11. **CARS specific** — no outside knowledge required; every correct answer provable from passage text
12. **Calculation questions** — exact numeric answer verified; distractors represent wrong calculation paths
13. **No duplicate topics within the same section** — no 3+ consecutive questions on same sub-skill
